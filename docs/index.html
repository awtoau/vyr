vyr

An IR-native UI renderer & embedded GUI toolkit in Rust — the executable spec for the vyvanse IR. Reference oracle first, editor canvas second, universal embedded toolkit endgame. Deterministic software rasterization, byte-exact partial-framebuffer banding, performance measured from the first commit, no_std core that compiles for STM32F4-class targets.
